# LevelUp Community & Documentation Hub

This repository is a community & documentation hub for the VS Code Extension “LevelUp - Gamify your coding workflow in VS Code”. 

Here you can [report 🐞issues](https://github.com/SinanFischer/LevelUp-Gamify-Your-Coding-Flow-in-VS-Code/issues) with the extension. For faster responses, ideas, or to exchange ideas, feel free to join the [💬 Discord community](https://discord.gg/sZvmsEV2JR) or write to me there directly.
